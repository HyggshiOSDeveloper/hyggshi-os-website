Architecture

Engineered for Performance

NexFetch is stripped of legacy baggage to ensure maximum speed and minimal system footprint.

Sub-10ms Benchmark

Written with low-overhead file system probes directly inspecting /proc and /sys. Renders virtually instantly upon launching your terminal.

Multi-Distro & Package Engine

Auto-detects Hyggshi OS, Arch, Debian, Ubuntu, Fedora, Alpine, Void, NixOS, and accurately counts packages across pacman, apt, flatpak, and dnf.

Modular ASCII & Custom Art

Switch between official Hyggshi OS logos, minimalist small tags, or load custom custom ASCII files from your ~/.config/nexfetch/ directory.

Quick Start

Install NexFetch

Run NexFetch on any Linux distribution or Hyggshi OS environment with a single command.

Recommended

Automated One-Liner (Hyggshi OS & Linux)

Downloads the latest executable and places it in /usr/local/bin/nexfetch.

curl -fsSL https://raw.githubusercontent.com/Hyggshi-OS-Foundation/nexfetch/main/install.sh | bash

Build & Install from Source

For developers who prefer compiling from source with custom flags.

git clone https://github.com/Hyggshi-OS-Foundation/nexfetch.git && cd nexfetch && sudo make install
Reference

CLI Flags & Options

Flag / Parameter Description Default
-h, --help Display command usage options and exit. —
-v, --version Print the NexFetch build version. 1.2
-c, --config <path> Specify an alternate configuration file path. ~/.config/nexfetch/config.conf
-a, --ascii <name> Override detected OS ASCII art (e.g., hyggshi, arch, debian, ubuntu). auto
--clean Print system info only without the ASCII art block. false
--color <palette> Set color scheme: cyan, blue, emerald, amber, purple. cyan
