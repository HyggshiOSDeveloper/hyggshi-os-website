We're introducing a new direction for Hyggshi OS: **two dedicated editions**, each built for a different kind of user. This post covers the **Debian Edition**.

## Why Split?

Up until now, Hyggshi OS 1.4.0 "Verdant Valley" shipped on a single Debian trixie base with Cinnamon. It worked, but Debian's clean base meant more manual work — including networking quirks that Ubuntu/Mint-based systems don't run into as often.

Rather than compromise on one base for everyone, we're splitting the project:

- **Debian Edition** — the research-first branch, built from a clean Debian base
- **Mint Edition** — a more plug-and-play branch, inheriting Mint's driver and network stack out of the box

![image](/Resources/posts/27-08-2026/OS2.png)

## What Debian Edition Is For

This edition stays true to the original philosophy of Hyggshi OS: **build everything from scratch**. It's the DIY, advanced branch — for people who want full control over the base system and don't mind doing some extra setup along the way.

- Debian trixie base, Cinnamon desktop
- Full control over kernel profile, package selection, and build configuration
- Config powered by our own DSL, **Hyggshi Configuration Language (HCL)**
- Best suited for testing, contributing, and exploring the HORT ecosystem close to the metal

## What's Next

The Mint Edition will follow shortly, aimed at users who want something closer to "just works" out of the box.

Both editions will share the same app ecosystem — NexCode, Nexfetch, HyggshiCut — just built on different foundations.

## Why This Matters

Instead of forcing one base to fit every kind of user, Hyggshi OS now offers a real choice: dig deep with Debian Edition, or get going fast with Mint Edition. Same ecosystem, same philosophy, different starting point.

More updates coming soon as both editions take shape.
